How to run the app
To run the app frontend+backend, follow these steps:
1. Make sure you have Java 17 or later installed on your machine.
2. Make sure you have Maven installed on your machine.
3. Clone the repository to your local machine.
4. Open a terminal and navigate to the root directory of the cloned repository.
5. Run the following command to build the project and start the application:
   ```
   mvn spring-boot:run
   ```
6. Once the application starts, you can access it in your web browser at `http://localhost:8080`.
